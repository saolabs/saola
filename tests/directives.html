📋 Blade Directives Reference

Danh sách đầy đủ các Blade Directives trong Laravel Framework

STT Loại Open Close Chức Năng Code Mẫu Kết Quả Hiển Thị
🎯 CẤU TRÚC ĐIỀU KHIỂN
1 Đóng mở @if($condition) @endif Kiểm tra điều kiện, thực thi code nếu điều kiện đúng
@if($user->isAdmin())
Xin chào Admin!
@endif
Xin chào Admin!
2 Đơn @elseif($condition) - Kiểm tra điều kiện thay thế khi @if không thỏa
@if($score >= 90)
Xuất sắc
@elseif($score >= 80)
Giỏi
@endif
Giỏi (nếu $score=85)
3 Đơn @else - Thực thi code khi tất cả điều kiện trên không thỏa
@if($user->isPremium())
Premium
@else
Free
@endif
Free
4 Đóng mở @unless($condition) @endunless Ngược lại với @if, thực thi khi điều kiện SAI
@unless($user->isBanned())
Bạn có thể đăng bài
@endunless
Bạn có thể đăng bài
5 Đóng mở @isset($variable) @endisset Kiểm tra biến có tồn tại và không null
@isset($user->name)
Tên: {{ $user->name }}
@endisset
Tên: John Doe
6 Đóng mở @empty($variable) @endempty Kiểm tra biến rỗng (empty)
@empty($posts)
Không có bài viết
@endempty
Không có bài viết
7 Đóng mở @switch($value) @endswitch Cấu trúc switch-case để kiểm tra nhiều giá trị
@switch($status)
@case('pending')
Đang chờ
@break
@default
Khác
@endswitch
Đang chờ
🔐 XÁC THỰC
8 Đóng mở @auth
@auth('guard')		 @endauth Kiểm tra người dùng đã đăng nhập
@auth
Xin chào, {{ auth()->user()->name }}
@endauth
Xin chào, Nguyen Van A
9 Đóng mở @guest
@guest('guard')		 @endguest Kiểm tra người dùng CHƯA đăng nhập
@guest
<a href="/login">Đăng nhập</a>
@endguest
<a href="/login">Đăng nhập</a>
10 Đóng mở @can('ability') @endcan Kiểm tra quyền của người dùng (authorization)
@can('edit', $post)
<button>Sửa</button>
@endcan
<button>Sửa</button>
11 Đóng mở @cannot('ability') @endcannot Kiểm tra người dùng KHÔNG có quyền
@cannot('delete', $post)
Bạn không có quyền xóa
@endcannot
Bạn không có quyền xóa
12 Đơn @elsecan('ability') - Kiểm tra quyền thay thế trong chuỗi @can
@can('edit', $post)
Sửa
@elsecan('view', $post)
Xem
@endcan
Xem
13 Đóng mở @canany(['edit', 'delete']) @endcanany Kiểm tra có BẤT KỲ quyền nào trong danh sách
@canany(['edit', 'delete'], $post)
<div>Actions</div>
@endcanany
<div>Actions</div>
🔁 VÒNG LẶP
14 Đóng mở @for($i=0; $i<10; $i++) @endfor Vòng lặp for truyền thống
@for($i = 1; $i <= 5; $i++)
Số {{ $i }}
@endfor
Số 1
Số 2
Số 3
Số 4
Số 5
15 Đóng mở @foreach($items as $item) @endforeach Lặp qua từng phần tử trong mảng/collection
@foreach($users as $user)
<li>{{ $user->name }}</li>
@endforeach
<li>John</li>
<li>Jane</li>
<li>Bob</li>
16 Đóng mở @forelse($items as $item) @endforelse Foreach với xử lý khi mảng rỗng
@forelse($posts as $post)
{{ $post->title }}
@empty
Không có bài viết
@endforelse
Không có bài viết (nếu $posts rỗng)
17 Đóng mở @while($condition) @endwhile Lặp khi điều kiện còn đúng
@php $i = 0; @endphp
@while($i < 5)
{{ $i++ }}
@endwhile
0 1 2 3 4
18 Đơn @continue
@continue($condition)		 - Bỏ qua lần lặp hiện tại, chuyển sang lần kế tiếp
@foreach($users as $user)
@continue($user->blocked)
{{ $user->name }}
@endforeach
John
Jane (bỏ qua users bị block)
19 Đơn @break
@break($condition)		 - Thoát khỏi vòng lặp hoàn toàn
@foreach($items as $item)
@break($item->id == 5)
{{ $item->name }}
@endforeach
Item 1
Item 2
Item 3
Item 4
📄 KẾ THỪA TEMPLATE
20 Đơn @extends('layout.app') - Kế thừa từ template cha
@extends('layouts.master')

@section('content')
Nội dung
@endsection
Kế thừa toàn bộ HTML từ layouts.master
21 Đóng mở @section('name') @endsection
@show		 Định nghĩa một section có thể override
@section('sidebar')
<ul>Menu</ul>
@endsection
<ul>Menu</ul>
22 Đơn @yield('name')
@yield('name', 'default')		 - Hiển thị nội dung của section từ view con
<div class="content">
@yield('content')
</div>
<div class="content">
Nội dung từ view con
</div>
23 Đơn @parent - Hiển thị nội dung section từ template cha
@section('sidebar')
@parent
Thêm nội dung mới
@endsection
Nội dung từ cha
Thêm nội dung mới
24 Đơn @show - Kết thúc section và hiển thị ngay nội dung
@section('title', 'Trang chủ')
@show
Trang chủ
📦 INCLUDE VIEWS
25 Đơn @include('view.name')
@include('view', ['data' => $value])		 - Nhúng một view khác vào view hiện tại
@include('partials.header')
@include('user.profile', ['user' => $user])
Nội dung từ partials.header
26 Đơn @includeIf('view.name') - Include view nếu view tồn tại
@includeIf('partials.optional-nav')
Hiển thị nếu view tồn tại, nếu không thì bỏ qua
27 Đơn @includeWhen($condition, 'view') - Include view khi điều kiện đúng
@includeWhen($user->isAdmin(), 'admin.panel')
Nội dung admin.panel nếu là admin
28 Đơn @includeUnless($condition, 'view') - Include view khi điều kiện SAI
@includeUnless($user->isBanned(), 'comments.form')
Hiển thị form comment nếu không bị ban
29 Đơn @includeFirst(['view1', 'view2']) - Include view đầu tiên tồn tại trong mảng
@includeFirst(['custom.header', 'default.header'])
Nội dung từ custom.header hoặc default.header
30 Đơn @each('view', $data, 'item') - Render view cho mỗi item trong collection
@each('partials.task', $tasks, 'task', 'partials.no-tasks')
Render partials.task cho mỗi task
📚 STACKS (Scripts & Styles)
31 Đóng mở @push('name') @endpush Thêm nội dung vào cuối stack
@push('scripts')
<script src="custom.js"></script>
@endpush
Script được thêm vào cuối stack 'scripts'
32 Đóng mở @prepend('name') @endprepend Thêm nội dung vào đầu stack
@prepend('styles')
<link href="first.css">
@endprepend
CSS được thêm vào đầu stack 'styles'
33 Đơn @stack('name') - Hiển thị tất cả nội dung trong stack
<head>
@stack('styles')
</head>
<head>
<link href="first.css">
<link href="second.css">
</head>
34 Đóng mở @once @endonce Chỉ render nội dung một lần duy nhất
@once
@push('scripts')
<script>...</script>
@endpush
@endonce
Script chỉ được push 1 lần dù include nhiều lần
🧩 COMPONENTS
35 Đóng mở @component('component') @endcomponent Render component (cũ, nên dùng class components)
@component('alert')
<strong>Lỗi!</strong>
@endcomponent
HTML từ component alert với nội dung "Lỗi!"
36 Đóng mở @slot('name') @endslot Định nghĩa slot trong component
@component('card')
@slot('title')
Tiêu đề
@endslot
@endcomponent
Component card với slot title = "Tiêu đề"
37 Đơn @props(['name' => 'default']) - Định nghĩa props cho anonymous component
@props(['type' => 'info'])
<div class="alert-{{ $type }}">
<div class="alert-info">
38 Đơn @aware(['parentData']) - Truy cập data từ component cha
@aware(['color' => 'gray'])
<div class="bg-{{ $color }}">
<div class="bg-blue"> (nếu cha truyền color='blue')
💻 PHP & RAW
39 Đóng mở @php @endphp Viết code PHP thuần trong template
@php
$counter = 0;
$total = count($items);
@endphp
Không có output, chỉ thực thi PHP
40 Đóng mở @verbatim @endverbatim Không parse Blade syntax (dùng cho Vue/Alpine)
@verbatim
<div>{{ vueVariable }}</div>
@endverbatim
<div>{{ vueVariable }}</div> (giữ nguyên)
📝 FORMS & CSRF
41 Đơn @csrf - Tạo hidden input chứa CSRF token
<form method="POST">
@csrf
...
</form>
<input type="hidden" name="_token" value="abc123...">
42 Đơn @method('PUT') - Tạo hidden input để spoof HTTP method
<form method="POST">
@csrf
@method('DELETE')
</form>
<input type="hidden" name="_method" value="DELETE">
43 Đóng mở @error('field') @enderror Hiển thị lỗi validation cho field cụ thể
@error('email')
<span>{{ $message }}</span>
@enderror
<span>Email không hợp lệ</span>
🌍 ENVIRONMENT
44 Đóng mở @env('local')
@env(['local', 'staging'])		 @endenv Kiểm tra môi trường ứng dụng
@env('local')
<!-- Debug tools -->
@endenv
<!-- Debug tools --> (nếu env=local)
45 Đóng mở @production @endproduction Kiểm tra môi trường production
@production
<!-- Analytics code -->
@endproduction
<!-- Analytics code --> (chỉ trên production)
🛠️ UTILITIES
46 Đơn @json($data) - Chuyển đổi dữ liệu PHP sang JSON
<script>
var data = @json($array);
</script>
var data = {"name":"John","age":30};
47 Đơn @dd($data) - Dump và die (debug)
@dd($user)
@dd($user, $posts)
Hiển thị dump data và dừng thực thi
48 Đơn @dump($data) - Dump data để debug (không dừng execution)
@dump($variable)
@dump($user, $settings)
Hiển thị dump data, tiếp tục thực thi
49 Đơn @hasSection('name') - Kiểm tra section có tồn tại không
@hasSection('sidebar')
<div>...</div>
@endif
<div>...</div> (nếu có section 'sidebar')
50 Đơn @sectionMissing('name') - Kiểm tra section KHÔNG tồn tại
@sectionMissing('sidebar')
<div>Default</div>
@endif
<div>Default</div> (nếu không có section)
51 Đóng mở @session('key') @endsession Kiểm tra và lấy giá trị session
@session('status')
<div>{{ $value }}</div>
@endsession
<div>success</div>
52 Đơn @js($data) - Chuyển đổi PHP sang JavaScript (Laravel 9.31+)
<script>
const config = @js($config);
</script>
const config = {api_key: "abc", debug: true};
✨ CUSTOM DIRECTIVES
53 Custom @directive - Bạn có thể tạo custom directives riêng trong AppServiceProvider
// AppServiceProvider.php
Blade::directive('datetime', function ($expression) {
return "<?php echo ($expression)->format('m/d/Y'); ?>";
});
